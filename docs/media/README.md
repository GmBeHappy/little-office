# Workspace showcase

- [Workspace mockup](workspace-mockup.png): 1600 × 900 PNG.
- [Feature showcase](workspace-showcase.mp4): 22.5 seconds, 1600 × 900, 30 fps, H.264 MP4. Silent, with gentle camera movement and crossfades; suitable for looping or sharing.
- [Editable mockup](showcase.html): four scenes, selected with `?scene=0` through `?scene=3`. Designed at 1600 × 900.

The showcase illustrates the shared office, nearby voice, collaborative whiteboard, and themed maps. People, workspace names, drawing content, and activity are fictional. These are promotional mockups, not screenshots of a connected production session or proof of live functionality. Map/avatar art comes from `public/landing/`, generated by the project's shared drawing code. No external stock assets, real account data, or audio are used.

## Regenerate

Install repository dependencies, FFmpeg (including ffprobe), and Playwright Chromium:

```sh
bun install --frozen-lockfile
bunx playwright install chromium
bun scripts/prepare-landing.ts
node scripts/create-showcase.mjs
```

The script verifies that all four scenes load their images without browser errors, renders the PNG, and uses FFmpeg to encode the video. Temporary frames are removed afterward. Set `CHROME_PATH` to use an installed Chrome executable; `FFMPEG` and `FFPROBE` can override those executable paths.

The public website used in all scenes is **https://www.littleoffice.app**. These materials are covered by the repository [license](../../LICENSE).
